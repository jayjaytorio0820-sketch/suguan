# Suguan

Android app ni Jay Jay para sa awtomatikong pagsusugo ng mga guro sa 11 dako tuwing Linggo.

- Rotation na walang ulit (11 Linggo bawat ikot), Set A/B/C…
- Attendance (absent) at kusang pag-adjust, hold = history (green/red), drag = ilipat
- Ilang guro bawat dako (hal. 3 sa kapilya), paalala pagkatapos ng 11 Linggo, reset bawat quarter
- History at bilang ng absent bawat buwan / quarter, backup at restore

## APK
GitHub Actions ang bumubuo ng `Suguan.apk` sa bawat push sa `main`.
I-download sa branch na **apk** → `Suguan.apk`.
